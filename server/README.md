# Сервер приложения «Глава → курс»

Локальный сервер одного пользователя поверх конвейера `engine/glava`. Слушает только `127.0.0.1`, своей базы нет: данные читаются из файлов конвейера. Контракт — `../docs/API.md`.

## Запуск

Одна команда из папки `server` (нужен [uv](https://docs.astral.sh/uv/), Python 3.12 uv найдёт сам):

```
uv run glava-server
```

Адрес: <http://127.0.0.1:8200/api/health>. Остановка — Ctrl+C. При остановке или падении сервера идущие сборки тоже останавливаются, а после запуска помечаются `failed`; повторная сборка берёт готовые ответы модели из кэша.

## Настройки

| Переменная | Смысл | По умолчанию |
| --- | --- | --- |
| `GLAVA_ROOT` | корень репозитория | папка над `server` |
| `GLAVA_PORT` | порт | `8200` |
| `GLAVA_RUN_COMMAND` | команда сборки, список JSON | `["uv", "run", "glava"]` |
| `GLAVA_ADMIN_PASSWORD` | пароль автора, от 8 знаков; без него открыто всё | нет |
| `LLM_PROVIDER`, `LLM_MODEL`, `CLAUDE_EXE` | передаются конвейеру | как в конвейере |

Чтобы проверить интерфейс без трат, подставьте свою команду в `GLAVA_RUN_COMMAND`: к ней добавятся имя этапа, глава и параметры.

Запуски настоящей командой тратят деньги. POST принимается только со страниц `http://127.0.0.1:5190`, `http://localhost:5190` и с адреса самого сервера.

## Где что лежит

- `work/runs/<id>.json` и `work/runs/<id>.log` — запись и журнал запуска;
- `work/review_uploads/<номер>/` — распакованный пакет на проверку (только `package.json` и картинки, файлы с «key» в имени отброшены);
- `out/<глава>/` отдаётся по адресу `/course/<глава>/…`.

## Тесты

```
uv run pytest --cov
```

Настоящий конвейер в тестах не вызывается: вместо него `tests/fake_glava.py`.
