# Доменный пакет «бурение»

Собран из двух черновиков (ветки `feature/domain-drilling` и `feature/video-elevenlabs`). Общий пакет по бурению нефтяных и газовых скважин. Собран заранее, без тестовой главы: её тему мы не знали. Состав и читатели файлов — как в `workspace/domain/geology/README.md`. Подключается строкой `"domain": "drilling"` у главы; код движка не менялся.

## Что чем нарисовать

- Колонны, цемент, хвостовик, перфорация, путь раствора — `well`.
- Окно давлений, выбор глубины спуска, проявление и поглощение — `mudwindow`.
- Зависимости (скорость от нагрузки, реологическая кривая, глубина от времени) — общий `plot`; величины — `bars`; порядок действий — `flow`.
- Долото, КНБК, траектория, буровая установка — своих шаблонов нет. Если глава об этом, нужен новый шаблон.

Правила для новых шаблонов: импорт только из `glava.sdk`; числовые поля на рисунке не печатать, если это не числа главы.

## Откуда содержание и чему верить

Написано моделью-помощником по общим знаниям отрасли, без книг организаторов, без поиска в сети и без проверки буровиком. Чисел и нормативов нет намеренно. Уверенность стоит в `now_practice.md`; определения глоссария и аналогии специалист не вычитывал. Определение автора главы главнее.

## Когда выдадут главу

1. Прочитать главу, выписать термины и обозначения, дополнить `glossary.md` (страницы) и `pronunciation.md`.
2. Убрать заблуждения не по теме, добавить 3–5 по теме.
3. Добавить в `physics_checklist.json` пункты по теме главы.
4. Пробная сборка `layer --limit 3`; посмотреть, какие узлы остались без предметного рисунка.
