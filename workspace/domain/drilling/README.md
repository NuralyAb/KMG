# Доменный пакет «бурение»

Всё предметное для глав по бурению и конструкции скважины. Код движка не меняется: у главы в `workspace/chapters.json` стоит `"domain": "drilling"`.

Собран 26.11.2026 до выдачи главы, по чек-листу «Бурение и скважина» из ТЗ и общим отраслевым знаниям. Черновик написал ИИ-ассистент примерно за 10 минут, вычитка специалистом не проводилась, минуты человека не замерялись. Под саму главу сдвига дополняются глоссарий со страницами, произношения и заблуждения; минуты записываются в `workspace/metrics.csv`.

| Файл | Что внутри |
| --- | --- |
| `misconceptions.json` | заблуждения новичков |
| `difficulty.md` | восемь типов трудности на примерах бурения |
| `physics_checklist.json` | чек-лист корректности |
| `styleguide.json`, `axes.json` | цвета, метки, направление осей |
| `pronunciation.md`, `stress_dictionary.md` | чтение обозначений и ударения |
| `glossary.md` | термины с английским аналогом; страницы вписываются под главу |
| `it_bridges.md`, `now_practice.md` | ИТ-аналогии и «было — сейчас» |
| `video/gas_kick.py` | сцена: газовая пачка в открытой и закрытой скважине |

Рисунки курса строят общие шаблоны движка: `flow`, `compare`, `plot`, `bars`.
