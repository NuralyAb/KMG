Найди ошибки в черновике учебного материала по тексту главы.

Верни только JSON: {"remarks":[{"target":"…","category":"…","severity":"…","problem":"…","fix":"…","page_pdf":0,"quote":"…"}]}.
target — id элемента; category — одна из: overgeneralization, sign_flip, measured_vs_inferred, lost_condition, missing_caveat, wrong_scaling, wrong_mechanism, outdated_as_current, analogy_without_limit, frame_error, other; severity — critical, significant или minor; fix — исправленная формулировка; page_pdf и quote — страница и цитата главы, которые это подтверждают.
