# Лаборатория и живой факт

Всё работает без модели и без сети. Модули: `impact`, `lab`, `transfer`.

## Лаборатория

Собирается вместе с курсом: `workspace/out/<глава>/lab.html`. Вход — кнопка «Лаборатория» в курсе.

| Раздел | Что делает | Откуда данные |
| --- | --- | --- |
| Слепая скважина | две скважины Volve: ответы с уверенностью, заключение оператора, два «робота» с порогом | `workspace/domain/<домен>/practice/*.json` |
| Диагноз | 10 вопросов, карта заблуждений; тот же диагноз стоит у заданий курса | поле `misconception` вариантов ответа |
| Ручной труд | решения команды и выгрузка CSV | `inefficiency_lens` и `data_meaning` узла |
| Паспорт | `lab.html#passport`, у ученика в меню нет | `glava passport` |

### Что проверено и что нет

- Классы интервалов сверяются скриптом с интерпретацией оператора (SAND_FLAG, VSH, PHIF, SW): при расхождении данные не собираются.
- «Высокое сопротивление = нефть» угадывает 5 из 10, при любом пороге не больше 6. Правило Pн = ρп/ρвп угадывает 10 из 10. Интервалы выбрали мы: это показ принципа, а не точность на всей скважине.
- Порог Pн = 3 взят из примера главы. Границы 0,10 для пористости и 75 API для ГК — наш выбор.
- Испытаний интервалов в наборе нет. Геолог тексты не смотрел.

Пересобрать данные: `python scripts/volve_practice.py <папка spwla_volve> workspace/domain/geology/practice/volve_blind.json`. Тексты — в `volve_blind.texts.json`.

## Живой факт

Экран: глава → «Живой факт». Команды: `glava fact <глава>`, `glava fact <глава> --apply [--accept]`. `glava rebuild` сперва делает то же, потом ролики.

- Число меняется само, только если заменено ровно одно число и фраза о том же: общие слова, то же обозначение или другие числа утверждения рядом.
- Слова автора (примеры, задачи, таблицы, формулы) не правятся. Место со старым числом попадает в журнал.
- Расчётное задание скрывается, пока его не составят заново. Рисунок со старым числом получает пометку в подписи.
- Симулятор только показывается в списке: его числа код не меняет.
- Правка с экрана пишет минуты и причину в `manual_edits.csv`.
