# Симуляторы в курсе

3D-симулятор — это JSON-сцена и проигрыватель. Движение, кривые и итог считает одна модель, поэтому картинка не расходится с данными. Сеть не нужна.

## Как попадает в курс

1. `simulators/course.json` связывает шаг главы, сцену и утверждения слоя.
2. `cd simulators; npm ci; npm run course` проверяет физику сцен, пишет `work/<глава>/simulations.json`, `work/<глава>/simulations/` и проигрыватель `engine/glava/course/assets/sim/`.
3. `uv run glava course <глава>` собирает курс. Node для этого шага не нужен, модель тоже.

Источники в окне «Откуда это и что упрощено» берутся из утверждений слоя. Правка `layer.json` и пересборка курса меняют и их. Если утверждения или шага больше нет, сборка останавливается с понятной ошибкой.

Глава без симуляторов остаётся лёгкой. С ними курс больше примерно на 6 МБ; предел ТЗ — 30 МБ без видео.

Тексты и числа сцены написаны вручную и при правке слоя сами не меняются: меняются только источники. После правки чисел проверьте сцену.

## Сделать новую

Вручную: скопировать сцену из `simulators/scenes`, см. `simulators/README.md`.

Через модель (опыт, с настоящей моделью ещё не прогонялось): `cd simulators; node agent/pipeline.mjs <имя> --book "<md>" --pages 34-35 --plan` показывает шаги бесплатно, без `--plan` тратит лимит. Потолки — `simulators/agent/steps.json`. Этот путь пока идёт от главы, а не от слоя.
