# Симуляторы в курсе

3D-симулятор — это JSON-сцена и проигрыватель. Движение, кривые и итог считает одна модель, поэтому картинка не расходится с данными. Сеть не нужна.

## Как попадает в курс

1. `simulators/course.json` связывает шаг главы, сцену и утверждения слоя.
2. `cd simulators; npm ci; npm run course` проверяет физику сцен, пишет `work/<глава>/simulations.json`, `work/<глава>/simulations/` и проигрыватель `engine/glava/course/assets/sim/`.
3. `uv run glava course <глава>` собирает курс. Node для этого шага не нужен, модель тоже.

Источники в окне «Откуда это и что упрощено» берутся из утверждений слоя. Правка `layer.json` и пересборка курса меняют и их. Если утверждения или шага больше нет, сборка останавливается с понятной ошибкой.

Глава без симуляторов остаётся лёгкой. С ними курс больше примерно на 6 МБ; предел ТЗ — 30 МБ без видео.

## Сделать новую

Вручную: скопировать сцену из `simulators/scenes`, см. `simulators/README.md`.

Агентом по узлу слоя: `uv run glava simulation <глава> --node <узел> --until design` делает только замысел, без `--until` доходит до конца и ставит сцену в курс. То же самое — кнопка «Сделать симулятор» на странице шага в приложении. Факты и цитаты берутся из слоя без модели; модель делает замысел, формулы, сцену, игру и смотрит кадры. Потолки — `simulators/agent/steps.json`, расход пишется в `metrics.csv`. Нужны Node.js 22, `npm ci` в `simulators`, Chrome и Python с playwright и Pillow. С настоящей моделью проверен только замысел: 1 вызов Sonnet, 30 с, $0,04. До конца ещё не прогонялось.

## Блоки и скорость агента

Шаг «сцена» пишет не отдельные тела, а крупные блоки (`simulators/src/models/blocks.js`): `layers`, `stack`, `well`, `log`, `invasion`, `inflow`, `contact`, `front`, `pores`, `depth`. Код разворачивает их в обычные объекты, функции, допущения и преувеличения. В готовой сцене блоков уже нет. Формат описан в `simulators/agent/CATALOG.md`, примеры — в `simulators/tests/blocks.demo.json`.

- «Сцена» и «игра» строятся одновременно и потом сверяются. Ключ `--serial` возвращает очередь.
- Исправление приходит патчем, остальной ответ не переписывается.
- Мелочи чинит код: тип шага, цвет линии, лишний ползунок, имя переменной в тексте.
- Четыре кадра и прохождение делаются за один запуск браузера (`tool.mjs … inspect`).
- `--eyes human` — кадры смотрит человек, модель не вызывается. `--note "…"` вместе с `--from шаг` — замечание человека к шагу.

### Образец и вычитка

- В запросы «модель», «сцена», «игра» входит образец другого узла, проверенный человеком (`simulators/agent/example.json`).
- Замысел сразу называет блоки, поэтому не обещает того, чего движок не умеет.
- Не проходят: неподвижная сцена, числа модели в вариантах ответа, разрез вне породы, флюиды по постоянным глубинам.
- Отдельный вызов `proof` сверяет тексты с фактами узла и правит только строки.
