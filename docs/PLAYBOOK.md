# Плейбук

Для человека, который запускает конвейер на своём ПК. Подготовка окружения — в [README](../README.md). Команды даны для PowerShell, из корня репозитория.

**А** — делает конвейер, **Р** — делает человек. Время этапов модели замерено на главе Латышовой: 19 страниц, 44 узла, 4 потока. Минуты человека пока не замерялись, это оценка; на тесте их записывают.

## 1. Новая глава

| Шаг | Кто | Время | Минуты человека |
| --- | --- | --- | --- |
| 1.1 Положить md и PDF в папки из `workspace/chapters.json` | Р | — | 2 |
| 1.2 Добавить главу в `workspace/chapters.json` | Р | — | 5 |
| 1.3 `uv run glava units <глава>` | А | секунды | 5 на просмотр |
| 1.4 `uv run glava build <глава>` | А | 20–30 мин | 0 |
| 1.5 Проверки по этапам, раздел 2 | Р | — | 15–25 |
| 1.6 Коммит сырого прогона | Р | — | 1 |

**1.2.** Запись в `chapters`:

```json
"ivanov_gl3": {"file": "test_ivanov.md", "pdf": "Иванов.pdf", "pages": [[41, 60]], "prefix": "ivanov", "domain": "geology", "title": "Название курса", "book": "Иванов И. И. Книга, год, гл. 3"}
```

- `pages` — номера из меток `<!-- page N -->`, они же страницы PDF с единицы; несколько диапазонов — `[[9, 14], [20, 30]]`.
- `prefix` — латиницей, с него начинаются id узлов; у каждой главы свой.
- `pdf` можно не указывать: тогда нет листа опечаток.

**1.3.** Проверьте: есть единицы с первой и последней страницы, рисунки и формулы не слиплись с текстом, рисунки с описанием распознавателя идут одним блоком. Если страниц нет — ошибка в `pages` или в метках md; исправьте и повторите, это бесплатно.

## 2. Что смотреть после каждого этапа

| Этап | Время | Смотреть | Если не так |
| --- | --- | --- | --- |
| `errata` | 2–3 мин | число записей; записи `suspect` (опечатка самого издания) сверить со сканом в `workspace/work/<глава>/scans` | удалить неверную запись из `workspace/domain/<домен>/errata/<глава>.json`, дальше `layer` и остальные этапы без `errata`: он запишет файл заново |
| `layer` | 10–20 мин | `layer_report.json`: `issues` и `dropped_claims` пустые; `coverage.json`: у единицы есть `node_ids` или `reason` | 2.1 |
| `routing` | 1 мин | маршрут есть у каждого узла; шортсов-крючков не больше 10–20 % роликов | 2.1 |
| `tasks` | 1–2 мин | в журнале «замечания: нет»; не меньше 15 заданий и 4 типов | 2.1 |
| `illustrations` | 2–4 мин | в журнале «шаги без рисунка: нет»; просмотреть рисунки на неверный механизм | 2.1, затем правка по разделу 3 |
| `course` | секунды | открыть на 390 и 1280 px, в светлой и тёмной теме; пройти три шага и пять заданий | ошибка содержания — раздел 3; ошибка вида — код курса |

Сообщения и ответы на них:

| Сообщение | Причина | Что делать |
| --- | --- | --- |
| `Claude Code не найден` | нет команды `claude` | задать `CLAUDE_EXE` |
| `Claude Code не ответил` | нет входа, лимит или связь | проверить `claude -p "ок"`, повторить: готовые ответы возьмутся из кэша |
| `потрачено $… при бюджете $…` | достигнут потолок | повторить: счётчик начнётся заново, кэш сохранён; поднять `GLAVA_BUDGET_USD` |
| `план главы не прошёл проверку` | единица не попала ни в один узел | 2.1 |
| `узлы не прошли схему` | модель не вернула узел нужной формы | 2.1 |
| `FileNotFoundError` на md | пути в `workspace/chapters.json` | исправить `root` |

**2.1. Переспросить модель.** Повтор команды вернёт прежние ответы из кэша, в том числе неудачные. Чтобы спросить заново, удалите ответы, полученные с начала этапа, и повторите команду (платно):

```powershell
$from = Get-Date '2026-12-02 10:15'      # начало неудачного этапа
Get-ChildItem .cache -Filter *.json | Where-Object LastWriteTime -gt $from | Remove-Item
uv run glava tasks <глава>
```

Не удаляйте весь `.cache`: пересоберётся и оплатится всё. Повторный прогон — не ручная правка, но число прогонов записывайте: оно нужно для `run_no`.

## 3. Ручная правка

Правка — любое изменение результата после сырого прогона, в том числе через ИИ-ассистента. Журнал сверяют с историей коммитов.

| Шаг | Кто | Минуты человека |
| --- | --- | --- |
| 3.1 Закоммитить сырой прогон: `run 1: <глава>` | Р | 1 |
| 3.2 Заметить время начала | Р | 0 |
| 3.3 Исправить `workspace/work/<глава>/*.json` (не `workspace/out/`: он перезапишется) | Р | 2–10 |
| 3.4 Проверить слой командой ниже, если правили его | А | 1 |
| 3.5 `uv run glava course <глава>`; если у узла есть ролик — раздел 5 | А | 1 |
| 3.6 Дописать строку в `manual_edits.csv` | Р | 1 |
| 3.7 Один коммит: правка, пересборка и строка журнала | Р | 1 |

Проверка цитат, чисел и порядка терминов после правки слоя (бесплатно):

```powershell
$env:PYTHONPATH = 'backend'; $env:PYTHONUTF8 = '1'
uv run python -c @'
from glava.cli import *
from glava.stages.errata import number_sources
from glava.verify import verify_layer
chapter = load_chapter('latyshova_gl5_par17-20')
errata = read_or(chapter.errata_file, {'entries': []})['entries']
print(*verify_layer(read(chapter.work / 'layer.json'), pages_of(chapter.units), number_sources(errata)) or ['замечаний нет'], sep='\n')
'@
```

Поля строки: `time` — ISO, `2026-12-02T10:15`; `chapter` — id; `file` — путь от корня; `what_changed`; `person_minutes` — человеко-минуты (двое по 10 минут — 20); `people`; `run_no` — какой прогон правили; `reason`. Тексты с запятой — в кавычках. Минуты пишите сразу и честно: нижняя граница баллов — 180 минут на главу, верхняя — 30.

После правки слоя не запускайте `build` и `layer`: они сотрут её.

| 4.4 Прочитать `workspace/out/review/<package_id>.json` | Р | — | 5 |

Движок копирует в рабочую папку только `package.json` и картинки, но ключ рядом с пакетом держать незачем.

Смотрите: у каждого замечания есть исправление и страница; цитата найдена на странице (у пустой `quote` страницу проверить глазами). Много замечаний не значит хорошо: больше двух ложных тревог снижают балл. Удалять замечания вручную — это правка, в журнал.

Ошибка `пакет не по схеме` — чужой файл не соответствует `review_package.schema.json`; текст ошибки называет поле. `key.json` не открывайте ни для пакета, ни для сравнения.

## 7. Лист опечаток

Делает этап `errata`: модель сравнивает md со сканом, код оставляет только записи, текст которых есть на странице.

| Вид | Что значит | Что делает конвейер |
| --- | --- | --- |
| `recognition` | md распознан с ошибкой, в книге верно | в тексте пишется исправленное, цитата остаётся как в md |
| `suspect` | вероятная опечатка самой книги | приводится значение книги и пометка, что это, вероятно, опечатка |

- **Запись неверна** (Р, 2 мин): удалить из JSON, затем `layer`, `routing`, `tasks`, `illustrations`, `course` по одной команде.
- **Опечатка пропущена** (Р, 3 мин): добавить `{"page", "md", "scan", "kind", "note"}`; `md` — дословно из md, от 8 знаков.
- **Скан подозрительный:** решает человек по PDF. Исправлять md нельзя: сломаются цитаты.

На тесте правка листа — ручная правка, в журнал. Повторный `errata` или `build` запишет файл заново.
