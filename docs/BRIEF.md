# Хакатон «Глава → курс»: разбор ТЗ и план

Источник: `d:/kmg/хакатон` (ТЗ, пакет_вводных, books md, analysis books, книги, видео). Не публиковать: главы и ролики только локально.

## Задача

Конвейер «глава книги (md) → учебный слой (граф узлов) → маршрутизация форматов → спецификации → демо-курс (HTML без сервера)», плюс модуль проверки чужого пакета и ролики. Слой — единственный источник правды: курс собирается из него, а не из книги. Аудитория — цифровики без геологии. Движок не знает геологии, всё предметное лежит в доменном пакете.

## Обязательное (допуск)

1. Слой по `node.schema.json`: 100% единиц главы в таблице покрытия, у утверждения дословная цитата и страница, у поля пометка `by_model`, термин не раньше узла, где объяснён, примеры и задачи автора отдельными полями.
2. Машинная проверка: цитата найдена на своей странице (без учёта пробелов, переносов, регистра); каждое число слоя и курса есть в исходной единице.
3. Маршрутизация по `routing.schema.json` с оценками видеоёмкости 0–2 по пяти критериям; шортсов-крючков не больше 10–20% роликов.
4. Курс на главу: путь с временем и прогрессом, страница шага (15 блоков, пустые скрыты), не меньше 15 заданий и 4 типов из 5 (single, multiple, order, gap, calc), карточки, конспект с печатью, карта связей, не меньше одной иллюстрации на шаг. 390 и 1280 px без прокрутки вбок, текст от 16 px, строка до 70 знаков, светлая и тёмная тема, без сервера, до 30 МБ. Вставлять рисунки книги нельзя, только перерисовывать кодом с подписью.
5. Ролики: шортс 9:16 (40–90 с) и разбор 16:9 (1,5–3 мин) на двух разных главах, с паспортом по `passport.schema.json`, субтитрами, меткой происхождения, паузой на предсказание, вопросом на перенос. Кадры A и B считаются кодом из одной модели состояния.
6. Модуль проверки: вход `review_package.schema.json`, выход `review_output.schema.json`; не больше двух ложных тревог.
7. Репозиторий с тегом заморозки, плейбук, промпты, MANIFEST, замена моделей, доменный пакет, metrics.csv, manual_edits.csv.

Критическая ошибка (закреплено заблуждение, неверный механизм, нарушена причинность) обнуляет ролик или иллюстрацию. Две и больше — без призов.

## Решения

- Дизайн курса тот же, что в METU: токены рамки и листа, петроль, IBM Plex Sans (локально). Цвета пород, флюидов и кривых — строго из `styleguide.json`.
- Python 3.12 (uv), курс — статический HTML/CSS/JS без сборщика. Модель за интерфейсом провайдера, заменяется переменной среды.
- Модель не видит `key.json`. Автор решения случайно увидел начало ключа контрольного пакета (6 целей из 21): под них ничего не подстраивать, самопроверку гонять в чистом контексте.

## Этапы

1. Движок: разбор md на единицы, покрытие, проверки (цитаты, числа, термины, схемы), провайдеры, кэш, метрики.
2. Сборщик курса из слоя.
3. Доменный пакет геологии.
4. Слои, маршруты, задания, иллюстрации по трём обучающим главам.
5. Модуль проверки и самопроверка на контрольном пакете.
6. Ролики: симуляция → кадры → озвучка → паспорт.
7. Контрольные главы, заморозка, плейбук.
